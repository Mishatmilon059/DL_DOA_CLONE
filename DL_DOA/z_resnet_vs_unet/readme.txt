This folder contains the comparison logic between ResNet and UNet.

Files:
- comparative.py : Loads both models' RMSE and Pd dictionaries and creates a side-by-side comparison plot.

Usage:
    python comparative.py
    python z_resnet_vs_unet/comparative.py  // from main folder

Output:
    → figures_resnet_vs_unet/resnet_vs_unet_comparison.png

This folder contains the evaluation outputs for the ResNet-based model.

Files:
- resnet_results.png : Visualization of RMSE and Pd vs SNR curves for L=3, QP=16.
- resnet_rmse.pkl     : Dictionary of RMSE values per (L, SNR, QP) tuple.
- resnet_pd.pkl       : Dictionary of Pd (probability of detection) values per (L, SNR, QP) tuple.

Example RMSE key:
    (3, 10, 16) → RMSE value in degrees

These files are generated by executing z_resnet/main.py.

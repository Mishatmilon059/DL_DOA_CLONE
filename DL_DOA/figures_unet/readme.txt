This folder contains the evaluation outputs for the UNet-based model.

Files:
- unet_results.png : Visualization of RMSE and Pd vs SNR curves for L=3, QP=16.
- unet_rmse.pkl    : Dictionary of RMSE values per (L, SNR, QP) tuple.
- unet_pd.pkl      : Dictionary of Pd (probability of detection) values per (L, SNR, QP) tuple.

Example Pd key:
    (3, -5, 16) → Pd value (range 0 to 1)

These files are generated by executing z_unet/main.py.

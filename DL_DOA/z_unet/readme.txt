This folder contains the entry point for evaluating the UNet model.

Files:
- main.py : Runs inference using the UNet model and saves the RMSE, Pd, and result plots.

Usage:
    python main.py
    python z_unet/main.py  // from main folder


Output:
    → figures_unet/unet_results.png
    → figures_unet/unet_rmse.pkl
    → figures_unet/unet_pd.pkl

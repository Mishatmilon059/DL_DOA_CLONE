This folder contains the entry point for evaluating the ResNet model.

Files:
- main.py : Runs inference using the ResNet model and saves the RMSE, Pd, and result plots.

Usage:
    python main.py
    python z_resnet/main.py  // from main folder

Output:
    → figures_resnet/resnet_results.png
    → figures_resnet/resnet_rmse.pkl
    → figures_resnet/resnet_pd.pkl

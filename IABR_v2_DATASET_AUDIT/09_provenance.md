## 1. What the original authors actually did (reported first)

**Base paper** (Lloria, Roger, Botella-Mascarell, Cobos, IEEE TVT 2026; local copy `papers/`, text in `scratch/p09_lloria_raw.txt`):

* FACT: Channel $H=\sqrt{n_t n_r}\sum_l \alpha_l a_r(\psi_l)a_t^H(\phi_l)$; observation $Y=W^HHF+Z$ with DFT codebooks taken from Roger et al. TSDCE (IEEE TWC 2021, ref [16] of Lloria); Eq. (7)-(10) rewrite $Y$ as a 2D-DFT of a sum of windowed complex sinusoids, "as demonstrated in [16]".
* FACT (Sec. IV-B, Table I): training data generated on the fly ("infinite training dataset"), SNR uniform in [-10, 25] dB, $L\in\{1..10\}$, $Q=P\in\{16,32\}$, $\alpha_l\sim CN(0,1/L)$, angles uniform in $[0,\pi]$, GT = sum of 2D Gaussians with $\sigma_1=\sigma_2=0.07$, chosen from $\{0.2,0.1,0.07,0.05\}$; 1000 test realizations per SNR; code at github.com/SandraRoger/DLDOA. Gaussian GT and MSE loss are stated to follow ref [42] (Pan et al., IEEE TNNLS 2022, "Deep learning-based 2-D frequency estimation of multiple sinusoidals" - **not opened by me**).
* FACT (Sec. IV-D): phase error of antenna $i$ is $\delta_i\sim U[-\delta_{max},\delta_{max}]$, independent across antennas, applied to the Tx and Rx arrays; $\delta_{max}\in\{1,2,5\}^\circ$; justified by ref [50] (Bakr & Johnson-type report, per Meneses ref [9]) and [51] (Somjit, Stemme, Oberhammer, EuMIC 2009). Table II reports SNR 0 and 20 dB. The paper itself states models were trained **without** impairments and that retraining with impaired data is future work.
* FACT (repo, opened): github.com/SandraRoger/DLDOA is GPL-3.0; README asks to cite IEEE TVT 2025 and PIMRC 2024.
* FACT (code, `DL_DOA/src/tvt_data_generation_v3.py:70-118, 486-492`): impairment = one draw `np.random.uniform(-d_max, d_max, size=nt)` per call, multiplied onto **every beam** (column) of F, a separate independent draw for W, redrawn for each example (the codebook functions are called inside the per-example loop), global unseeded `np.random`. No gain error.

**Meneses-Albala et al., J. Supercomputing 2026** (text `scratch/p09_meneses_raw.txt`):

* FACT (Sec. 2.2, lines 198-207): same model - $\delta_i\sim U[-\delta_{max},\delta_{max}]$, independent across antennas, on both Tx and Rx, $\delta_{max}\in\{1,2,5\}$, cites Bakr & Johnson (2009) and Somjit et al. (2009). They fine-tune a pre-trained U-Net per $\delta_{max}$ (Table 1: 10,000 impaired training samples, 4,800 validation samples over (L, SNR, PQ, $\delta_{max}$)); Table 2 compares base vs. freeze-90% fine-tuned models.
* FACT (line 1180): "Future work will extend the proposed fine-tuning strategy to address other impairments, such as amplitude errors."
* CONCERN (minor): the text says the error alters the "array responses in Eqs. (2),(3)" whereas the code puts it on the codebooks. DERIVATION: $W_0^H D^H a$ vs $W_0^H D a$ differ by conjugation of the error; because $U(-\delta,\delta)$ is symmetric the two are equal in distribution, so the difference is immaterial for statistics of the data.

## 2. Project lineage (what the project code is derived from)

* FACT: `dldoa_dataset_generation.py:1-30` header credits the paper and repo ("Code derived from the authors' official repository") and cites Sec. IV-B / Table I. It contains near-verbatim copies of `generate_points`, `ev`, `beamforming_vector_generation_P/Q` (with `error_deg`), `generate_noise`, `generate_channel_v2`, `gaus2d`, `generate_gt`, `validation_data_generator`, sigma default 0.07.
* FACT: `IABR_v2/iabr2_sim.py:8-13,28-38` imports that module (`DG`), takes `F_IDEAL/W_IDEAL` from it and reuses `DG.generate_points` ("Exact original angle sampler") and the same $\alpha\sim CN(0,1/L)$ sorted strongest-first rule. The vectorised `simulate()` (lines 41-60) is a rewrite; the notebook checks it against the original `generate_channel_v2` (physics checks, `notebook_src.py:279-296`).
* FACT: `scripts/generate_frozen_banks.py:1-4,27,47-53` builds the "official" eval bank by importing the authors' `validation_data_generator` directly (seed 42, $L=3$, SNR -10..25, $\sigma=0.07$); the calibration bank uses seed 43. Agent 01 independently reproduced it bit-exactly.
* FACT: the notebook loads the authors' evaluator (`TVT_Blob_Inference.py`) verbatim via `ast` (`notebook_src.py:302-312`) and the authors' official U-Net weights (port `UNetPaper`).
* FACT: project `LICENSE` is GPLv3 and the upstream repo is GPL-3.0 (opened). CONCERN (Low): `DL_DOA/src/*.py` carry no in-file attribution header (they are vendored with commit message "feat: add all files from authors' DLDOA repo"), and the v2 package files (`iabr2_sim.py`, `notebook_src.py`) import/derive from GPL code; if the thesis code is distributed, the GPL-3 terms and the upstream citation request would apply. I give no legal conclusion.

## 4. Overlap that deserves a closer look (no accusation)

1. **Impairment model identical to Meneses/Lloria** - clearly attributed and the comparison against their Table 2 is the purpose of the work. Overlap class (b). The only substantive risk is *interpretive*: because v2 is trained with impaired data whereas Lloria's models are not, "beating Table 2" compares a impairment-aware model with impairment-unaware baselines; Meneses' fine-tuned variants are the like-for-like comparison. (CONCERN, Medium, methodological, not provenance.)
2. **Tuning of the physics decoder on the project's own banks** (`tune_*`, seeds 9901-9904) is stated to be separate from T2 banks - fine for provenance.
3. **Uncited borrowed techniques** (NOMP, penalty-reduced focal loss, array-calibration unidentifiability): all standard in their fields, all are ideas rather than copied text/code; the omission is a citation-completeness issue only.
4. **Gain error** is the project's original contribution relative to the two papers; the report should present it as an assumption, which the v1 suite already does.
